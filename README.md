# Datadew Valley

An interactive pixel-art simulation of what it's like to live next to a data center, built for a Brown University HCI research study.

## Run it

```bash
npm install
npm run dev     # open the printed localhost URL
```

## Edit text

All text is in [`public/content/`](public/content/README.md). No coding is needed.

## Develop

`npm test` · `npm run typecheck` · `npm run build`. See [`plan.md`](plan.md) for the roadmap and [`CLAUDE.md`](CLAUDE.md) for conventions.
